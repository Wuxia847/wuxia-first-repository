# companion

给 bot 加一层**潜意识**：它不负责说话，只负责**记得住、感觉得到、有自己的时间**。
说话仍然交给大模型。

只用 Python 标准库 + SQLite，无第三方依赖。

```bash
python examples/demo.py     # 不需要联网，也不需要装任何东西
```

---

## 它解决什么问题

长期bot对话里，大模型有4个绕不过去的毛病：

1. **记不住**：上下文一长就被裁剪，重要的话和废话一起丢。
2. **没状态**：每天都是同一个语气，不会因为"三天没说话"而变。
3. **太听话**：永远不会主动开口，因为没人给它时间感和欲望。
4. **固定性**: 提示词不改说话风格永远不变。

加一层外面的大脑解决不了，得给模型一个**外部器官**：
把"发生了什么、现在什么感觉、我是谁"压缩成一小段文字，每轮喂回去。

---

## 核心观点（八条）

1. **事件只追加**，永不改写。所有记忆都从事件派生，可重建、可回指。
2. **记忆存原话，不写摘要**。摘要会引入错误，而且越总结越像"别人对ta的描述"。（但是由本地设计的脚本每次对话针对性去索引记忆，不全部注入）
3. **两侧都要记**。只记用户那一侧，后面提炼出的"ta的性格"必然全是复述。
4. **状态是散文，不是数字**。数字做坐标系，词才做感觉。
5. **两个时间尺度**：亲密按天增长，热度按小时衰减。停聊三天，热度掉 90%，亲密几乎不动。
6. **人格锚只读可迭代**。程序只能提议，人确认后才生效；要改就"新增替代旧"，保留演化史。
7. **主动性靠闸门控制**，不靠提示词。安静时段、每日上限、被忽略就退避。
8. **空是合法的**。想不起相关记忆就不给，没想说的话就留空。

## 结构

```
事件账 ──派生──▶ 引文卡 ──聚合──▶ 话题（未完成的事）
   │                │                 │
   │                └──── 检索 ────────┘
   ▼
状态（四维，可重算）──▶ 散文注入
   │
   ▼
人格锚（只读，带证据与谱系）
```

| 模块 | 作用 |
|---|---|
| `ledger.py` | 只追加的事件账 + 谁在说话 |
| `cards.py` | 引文卡（两侧、去重、人工保护、黑名单） |
| `topics.py` | 话题容器 + 生命周期 |
| `state.py` | 四维状态（双时间尺度）+ 散文渲染 |
| `retrieval.py` | 混合打分检索（空是合法的） |
| `anchors.py` | 人格锚：提议/校验/确认/谱系 |
| `gates.py` | 主动行为的六道闸门 |
| `gateway.py` | OpenAI 兼容网关（三档接管 + 请求卫生） |

## 怎么接到自己的系统上

1. **先只记录**：把网关设成 `passthrough`，跑一天，确认每轮对话都进了事件账。
2. **再上状态**：切 `enrich`，让模型看到状态散文和 2–3 条联想。
3. **最后接管**：切 `replace`，人格提示完全自持。
4. **主动行为最后开**：先把闸门调保守（每天 1 条），跑一周再放宽。

任何一步出问题，改一个环境变量就能退回上一步。

---

## 不要做的事

- 不要把原始事件账喂给模型（一定变成上下文黑洞）
- 不要用"聊天条数"衡量亲密
- 不要让人格锚自动改写（漂移会变成"ta慢慢变成了另一个人"）
- 不要在没有归因校验的情况下提炼人格（模型会把对方的话算成ta的话）
